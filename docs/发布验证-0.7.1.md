## 历史与回滚

GitHub 0.6.1 的五个附件保留原 ID、大小与 SHA-256。两个平台的旧标签仍指向原提交，Gitee 的旧发行页也保留。更新源码使用新增提交，Gitee 通过普通合并保留原有文档提交，没有强制推送或改写旧标签。

需要回滚时先备份工作区，再从历史发行页下载旧程序，或检出对应旧标签。版本回滚不等同于工作区数据回滚，不能推断旧程序支持所有新增设置。

本记录作为发布后的文档提交补充到 main；v0.7.1 标签、已发布的源码快照及程序附件保持固定。

## 限制

验证发生在现有 Windows x64 电脑，没有在干净 Windows 执行交互安装、升级或卸载，也没有第二台电脑结果。安装包下载与摘要检查通过，安装包载荷在发布前已核对，与测试程序一致；不能据此宣称所有系统都能安装运行。抖音真实样本仍待验证，在线视频平台状态可能改变。完整回归范围见 [测试报告](测试报告-0.7.1.md)。
