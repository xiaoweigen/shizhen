## 重建外部工具

FFmpeg 使用 MSYS2 UCRT64，安装 GCC、make、nasm、pkgconf 和 autotools。将源材料中的 FFmpeg、x264、x265、zimg 压缩包放入构建目录的 archives，运行 scripts/build_ffmpeg.sh。默认构建目录为通用的 C:/Framepick-codecs-build；可通过 FRAMEPICK_CODEC_BUILD 修改。构建记录给出实际工具版本与配置。GCC 使用文件路径映射，产物不包含开发者的工作区目录。

yt-dlp 可运行 python scripts/build_decoder.py 重建，它创建专用的构建虚拟环境。该最小版本支持本项目已验证的 Bilibili 解析下载；依赖浏览器模拟、特殊加密或其他可选库的平台能力不能据此保证。用户主动更新解析器后，新的官方二进制适用其随附许可。
