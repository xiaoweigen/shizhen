# 二进制发布准备

当前仅发布文档；没有上传本地安装包，也没有宣称已有安装包的全部公开分发义务已完成。

## 已准备

- 项目 MIT、中文署名说明、免责声明与第三方作者声明。
- 固定 video-mosaic 提交和原 MIT，Gyan 构建许可/信息，实际 yt-dlp exe 的嵌入式第三方许可。
- Python、PyAV、Pillow、PyInstaller、Electron、React 和 Ant Design 的实际许可原文。
- 开发版本的功能测试摘要、已知边界和隐私公开范围。

## 发布程序前仍要补齐

| 发布部分 | 必需材料或核对 |
| --- | --- |
| 维护者代码 | 获准公开的清理版源码，与发布程序匹配的版本/提交；排除个人路径、调试产物、Cookie、媒体与工作区 |
| Gyan FFmpeg/ffprobe | 实际构建对应的 FFmpeg 提交、链接的第三方库源代码和构建脚本/补丁/配置；验证可获取及与程序一致 |
| yt-dlp Windows exe | 固定发布的源码及 exe 中 GPL 依赖的对应源和必要构建材料；不能以 Unlicense 源码许可概括二进制 |
| PyAV 工作程序 | 实际轮子的 FFmpeg 9.0.2、libx264/libx265 及其他 DLL 的准确来源、许可和构建材料；根据组合方式落实 GPL/LGPL 要求 |
| Python/Pillow/Electron 与界面依赖 | 完整随附声明，包括 Chromium 与所有实际分发的递归依赖；无关开发工具不用复制到程序中 |
| 程序包 | 打包 MIT/免责/第三方声明、需要的 GPL/LGPL 原文及对应源获取方式；独立安装/升级/卸载验证、版本和程序摘要 |

GPLv3 对应源要求见 [许可第 6 条](../licenses/GPLv3.txt)；LGPL 的组合、修改和重新链接要求见 [LGPLv3](../licenses/LGPLv3.txt)。选择源码获取方式后需保证实际可取得，单独一张网址清单不能代替没有准备好的源材料。

Framepick 自己的代码可以采用 MIT；独立工具及组合二进制受各自条件约束。将来若分发组合工作程序，应按真实链接方式和组件许可确认分发条件，不能把完整安装包写为“全部仅 MIT”。
