以上两种下载程序使用独立数据目录，并从运行环境中移除开发工具路径。安装包的 **交互安装、升级与卸载** 尚未测试；解包运行不能代替这些检查。

发布后的 main 分支补充 `scripts/setup_electron.cjs`，使 `npm run setup` 显式准备 Electron。发布标签保持不变；使用标签源码时，可按 README 的补充步骤运行官方安装脚本。开发建议获取 main 分支最新源码。

## 已知边界与建议

- 尚未验证第二台电脑、干净 Windows 的交互安装、升级和卸载流程。免安装版与安装包须分别说明实际测试范围。
- 有效登录状态的抖音内容、平台限制和真实 HDR 素材仍待覆盖。
- 最小 yt-dlp 构建没有可选的浏览器模拟等库，不能保证全部平台兼容。
- 建议未来补充干净系统的安装验证与真实 HDR 样本；若更换依赖，重新核对许可、摘要与实际使用结果。

更完整的既有功能与压力记录见 [0.6.0 测试报告](测试报告-0.6.0.md)，二进制材料见 [对应源说明](二进制发布准备.md)。
