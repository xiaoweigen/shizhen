# 发布验证 0.6.1

本页记录公开版本的验证范围，不公开私有素材路径、观看链接、原视频或原始日志。

## 本地最终构建

| 检查 | 结果 |
| --- | --- |
| 类型检查、前端构建、处理程序打包、Windows 安装包构建 | 通过 |
| 清理版后端回归 | 59 项通过，在外部工具重建前执行；最终工具包另做下列真实素材验收 |
| 最终程序真实素材完整流程 | 20 项通过，使用经授权的本地视频和 Bilibili 视频 |
| 分段裁剪与画面操作 | 4 组通过；11 张分段裁剪截图尺寸、像素匹配，7 个预览时间边界正确 |
| 本地全长抽帧 | 0.5 秒间隔，75 张 PNG；逐张像素与实际帧时间匹配，9 张九宫格分页 |
| 在线解析、独立下载、完整抽帧 | 通过；下载后按 2 秒间隔得到 90 张图片，核对实际内容与时间 |
| 拼接与备注 | 单页生成、备注保存、字号、分页与图片加载通过 |
| 队列和数据 | 取消、重试、暂停、确认移除、重启恢复和原文件保留通过 |
| 隐私与资源 | 清单式发布；源码与 41,483 个 Python 编译代码对象检查未检出私人引用；程序无测试工作区、Cookie 和媒体缓存 |
| 分发材料 | 26 份固定第三方源材料、构建配方、配置、随包许可和 SHA-256 摘要 |

最终测试使用独立应用数据目录，程序运行时不依赖开发环境的 Node.js/Python。实际测试不生成演示视频，使用已有授权素材。后端通用回归使用可重复生成的测试夹具。

发布后进行，结果将在本页更新。上述本地构建结果不能代替下载后的验收。

## 已知边界与建议

- 尚未验证第二台电脑、干净 Windows 的交互安装、升级和卸载流程。免安装版与安装包须分别说明实际测试范围。
- 有效登录状态的抖音内容、平台限制和真实 HDR 素材仍待覆盖。
- 最小 yt-dlp 构建没有可选的浏览器模拟等库，不能保证全部平台兼容。
- 建议未来补充干净系统的安装验证与真实 HDR 样本；若更换依赖，重新核对许可、摘要与实际使用结果。

更完整的既有功能与压力记录见 [0.6.0 测试报告](测试报告-0.6.0.md)，二进制材料见 [对应源说明](二进制发布准备.md)。
