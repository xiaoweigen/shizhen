# 拾帧 0.6.0 测试报告（公开摘要）

测试日期：2026-10-02，Windows 11 x64。本摘要来自本地完整验收记录，隐去了个人目录、用户视频名称、观看链接、素材散列、截图和工作区数据。原始记录留存本地，未上传。

## 测试结论

最终免安装版通过 59 项处理层测试、29 组原功能、12 组新功能、5 组恢复边界及 20 组真实素材流程。另通过 5 种网格预设、4 项布局交互、3 组压力界面、画布缩放范围检查和 8 项随包 HDR 参考核对。每组含多次操作和断言，不能简单合并为一个测试总数。

一个本地竖屏样本按 0.5 秒全长导出 75 张 PNG 和 9 张九宫格拼图；一个在线样本实际下载后按 2 秒导出 90 张 PNG 和 10 张拼图。165 张 PNG 逐张核对像素及实际时间，另外 11 张分段裁剪 PNG 独立逐像素核对；本地原视频前后摘要一致。

## 方法与局限

测试使用独立用户数据和隐藏窗口。文件选择对话框由测试返回路径，之后执行实际保存和处理；打开文件/文件夹核对系统请求，没有逐点击验证 Windows 原生选择器、播放器或资源管理器。在线样本执行真实解析和完整下载，一次超时后重新运行成功，没有用旧缓存替代网络测试。

生成素材覆盖固定/可变帧率、H.264/HEVC/FFV1、旋转、像素比例、音视频时长差、无音轨、中文目录、同名冲突、损坏文件、切镜与不同裁剪画幅。HDR 使用生成 PQ/HLG 标记素材，对比独立 FFmpeg 解码/滤镜参考；映射开启时逐像素相同，关闭映射 RGB 平均通道差低于 1。

解析器检查使用官方发布信息；当前与随包同版本，没有真实跨版本升级可测。更新、激活、回退和失败保护采用真实官方二进制配合受控发布响应验证。

## 压力数据

| 场景 | 实际输出/操作 | 耗时/内存 |
| --- | --- | --- |
| 1秒静态4K，3840×2160、10fps；0.001秒间隔 | 999张原尺寸PNG，最近帧重复取样，并非999个不同源画面 | 97.92秒；处理峰值293.95MiB |
| 30分钟160×90、1fps；2秒间隔 | 899张PNG，末帧目标1798秒 | 4.51秒；处理峰值141.82MiB |
| 最终桌面读取4K999图 | 初始12张可见/邻近小图；翻页、3840px原图、拼接小图正常 | 渲染工作集254.60MiB |
| 100项目/500条素材引用 | 同一真实样本的独立列表条目，搜索/移动/置顶正常；不是500个不同编码文件 | 初次渲染3.351秒；工作集622.44MiB |


这些是本机样本数据，不代表所有动态 4K 长视频速度。五百条是同一源视频的独立引用，不是五百个不同编码文件。
