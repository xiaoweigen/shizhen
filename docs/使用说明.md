# 使用说明（0.7.1）

本文描述 0.7.1 的操作；Windows 程序在仓库相应版本的 Releases 提供，使用时先核对版本及文件摘要。

## 导入与抽帧

1. 添加单个或多个本地视频，也可拖入文件；先选择新导入视频所属项目。
2. 导入后自动预览最新视频，默认不勾选。点击列表项只切换预览；勾选用于批量处理。
3. 设置时间间隔、JPG/PNG、图片质量和宽度；每个视频单独保存截取范围，新视频默认完整时长。需要统一范围时点击“应用到已选视频”并确认。
4. 选择截图保存根目录。每个视频进入独立子目录，同名不同来源有冲突保护。
5. 单个视频点“抽帧当前视频”，多个视频先勾选再点“批量抽帧（已选 N 个）”。在底部查看进度，点击“查看处理队列”定位任务。
6. 进入结果查看截图或编辑拼图。图片按目标时间命名，例如 `0.5s.png`、`1s.png`。

默认不包含范围起点，结束时间不包含；可启用包含起点。选取最接近目标的实际视频帧，同距离优先前一帧，实际时间写入任务记录。取消保留已完成图片；重试核验已有图片。重复导出可选核验后跳过、另存一批或明确覆盖。

## 裁剪与画面操作

选中视频，在“视频操作 ▾”菜单进入“裁剪画面”，拖动选框、边框与角点，或输入像素位置和尺寸；可播放视频并拖动时间轴切换真实预览画面。先设默认区域，再添加不同时间段，例如 1～5 秒、6～10 秒。空档和范围外使用默认区域，初始默认是完整画面。

裁剪时段包含开始与结束，共用边界时后一段优先，内部重叠不允许。按目标截图时间切换区域，不对选框进行动画插值；缩放、旋转和像素宽高比处理后再裁剪。旧截图需要重新抽帧才能体现新裁剪。

默认 Ctrl + 加号/减号放大缩小，Ctrl + 0 适合画面，Ctrl + 1 实际大小，Ctrl + 滚轮缩放；空格加左键、中键或长按拖动平移，Esc 退出当前查看/裁剪或返回选图。“画面操作快捷键”中可修改并保存，输入备注时不会误触缩放。

快捷键输入框支持同时按多个按键；松开全部按键后确认。例如按住 Ctrl、Shift 和 X，再全部松开，记录为 Ctrl + Shift + X；也可使用 Q + W。F2 用于应用菜单，Alt 不再弹出顶部菜单。原图查看器优先处理最上层窗口的快捷键，Esc 只关闭当前查看器。

## 时间轴与视频长度剪切

截取范围、裁剪时段和预览位置使用 `分:秒.毫秒`，例如 `05:48.000`；超过一小时可输入 `时:分:秒.毫秒`。也可选择“毫秒”模式，输入 `65000`，旁边显示 `01:05.000`；毫秒须为整数。输入模式按工作区保存，所有时间编辑窗口共用。普通模式中单独输入 `1.5` 表示 1.5 秒，不解释为 1 分 5 秒。抽帧间隔仍以秒／张表示。时间轴默认展开，点击标题可以收起；绿色两端分别调整范围，拖动时预览同步到对应边界；中间绿色色块移动整段，黄色顶部拖动点只改变播放位置。黄色线与绿色选区共用轨道；窄选区可以用“＋”放大时间轴并横向滚动，点击“完整时间轴”还原。起止柄支持方向键微调，Shift 加方向键为一秒。可把当前位置设为起点／终点，或重置范围。结束时刻不参与按间隔抽帧；裁剪时段边界沿用上述规则。

预览下方的操作收在“视频操作 ▾”中。视频剪切默认关闭，必须先勾选“启用视频剪切”，才显示“剪切长度”；开关按视频保存。不勾选时按原视频抽帧，不执行长度剪切。重新关闭开关不会删除已经生成的副本。

剪切编辑支持保留或删除一个、多个时段，时间轴同步真实播放，可撤销最近二十次时段／模式操作。移除中间部分后，保存前询问是否拼接留下的片段：选“是”输出一段视频，选“否”分别输出并加入列表；关闭询问或返回编辑不会开始任务。保存文件夹由用户选择，原视频的位置和内容保持不变，同名副本另存。

剪切会重新编码为 H.264/AAC MP4，保留声音；精度受原视频帧率限制，画质和文件大小可能改变。空间裁剪只影响抽帧区域；长度剪切输出完整画面，不自动套用抽帧选框。完成后新视频加入当前项目并自动预览、默认不勾选，可继续抽帧。

## 选图、拼接和故事板

结果可逐张勾选、长按拖动选择/取消一段、Shift 连选、方向键及空格选择、Ctrl + A 选择本页，回车查看。跨页选择保留。

九宫格是 3 行 × 3 列，六宫格是 2 行 × 3 列，也有四格、十二格、十六格及自定义行列。行列决定每页容量；图片少时只保留实际有图的行，末行缺图的列留空。画面宽度、间距、备注和行列共同决定输出尺寸，界面显示实际像素。

“留备注区 · 故事板”默认关闭。开启后可输入镜号、画面、动作、对白和多行备注；备注区高度是最小值，长文自动增加同一行高度，不滚动或缩小字号。可保存模板、拖动排序、替换图片，或恢复时间顺序。

编辑页翻到需要的页后点击“生成当前拼接图”；“拼接全部图片”生成全部截图的拼图。已有拼图可选中并点击“编辑这张”，根据配方再生成新图，保留原图。

开启“画面内图序号 · ①②③”后，可选择带圈数字或普通数字、四角默认位置、颜色及大小。直接拖动序号可改变单张图上的位置；选中图片后可恢复角落，聚焦序号后也可用方向键微调。默认每张拼接图从 1 编号，可开启跨拼接图连续编号；位置随编辑草稿和拼图配方保存。

“拼接图”列表以宫格显示，默认每行三张；右上角可改为一到六张，重启保留。每页最多 20 张拼图。

## 项目、在线来源和维护

视频列表可新建项目、收放、置顶、搜索和批量移动；长按约 0.35 秒拖到项目或未分类，Esc 取消。移除前确认，列表移除不删除原视频和导出文件。

粘贴视频链接或分享文本，等待网站加载完毕、地址补全后再复制。点击“解析并下载”后先选择保存文件夹，取消选择不会解析或添加任务。解析成功自动下载至这个位置、展开项目并打开最新视频预览，默认不勾选。等待保存完成后直接播放；抽帧、裁剪和剪切使用同一份本地文件。下载进度和取消入口在预览区域及处理队列中显示；失败可以重试。相同链接的完整保存文件会复用；“视频操作 ▾”仍可选择再次下载并另存，同名文件保留。本地视频没有下载入口。

优先在允许的清晰度内选择便于直接播放的编码，不自动整段转码。原生播放器无法解码时，提供“重试原视频”“在系统中打开”和“生成兼容预览（可选）”。只有主动点击最后一项才会转换本地视频，长视频可能耗时并占用缓存空间，抽帧仍使用原保存文件。下载文件删除或移动后，需重新定位或明确再次下载，工具不会偷偷下载到缓存。

优先匿名解析，失败时尝试临时的独立访客会话；抖音还会尝试公开移动分享页。清晰度以平台公开提供的版本为准，登录权限、付费内容、地区限制和平台验证可能仍使解析失败。需要访问状态时由用户自行选择 Cookie 文件，不读取日常浏览器的登录信息。相关限制会显示在解析提示中。

“设置与维护”提供结果重新导入、归档恢复、素材重新定位、工作区备份/合并及解析器检查/更新/回退。备份保存引用、设置、模板和备注，视频与图片需另行备份。空间估算仅作参考，以写入前检查为准。

## 文件位置、真正删除与托盘

“视频操作 ▾ → 所在文件夹”通过系统文件管理器定位本地、下载或剪切视频；只有预览缓存时显示“预览缓存位置”。图片查看器和队列也有对应的所在文件夹入口。

列表原有移除按钮只移除记录。需要删除文件时选“删除视频文件”或结果中的“删除所选图片文件／删除导出文件”，核对红字提示、具体文件与路径，勾选确认后才可执行。工具只将所选文件移入系统回收站，不删除整个文件夹；成功删除的导出图片同步清理备注、索引、拼图配方引用；删除最后一页时自动返回有效页。全部导出文件删除后移除相应任务记录并关闭结果窗口；失败文件及其记录保留并提示。“删除导出文件”不包含原视频；真正删除视频后保留列表记录，便于重新定位。本地原视频会单独标红，请核对。处理中的文件需先取消或等任务完成。

第一次关闭窗口会询问“隐藏到托盘／直接退出／取消”，可以记住选择。“设置与维护 → 关闭窗口方式”随时修改。隐藏后下载、抽帧、剪切继续；单击或双击托盘图标恢复，右键可暂停／继续队列或退出。直接退出停止当前任务。重复启动会恢复既有窗口。

## 范围限制

Windows x64 优先；本地任务依次处理。单任务最多十万张截图、二百个裁剪时段，每张拼图最多二千四百万像素。大图或长备注超限时需减小宽度、行列或分页。完整验证边界见 [测试报告](测试报告-0.7.1.md)。
