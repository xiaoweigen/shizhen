# 拾帧 0.7.0 改进与后续建议

## 已完成

- 视频操作收入下拉菜单，长度剪切默认关闭，用户勾选后才出现入口；减少预览区常驻按钮。
- 时间范围改为分:秒.毫秒，时间轴默认展开且可收起；拖动同步真实播放，支持当前点设边界及重置。
- 裁剪可播放，在线视频自动准备兼容副本，进度、取消、重试可见；AV1 软件解码避免依赖本机硬件支持。
- 长度剪切支持保留／删除多个时段及撤销；多段保存前确认拼接或分别输出，原文件保留，同名另存。
- 系统文件位置入口统一；真正删除与记录移除分开，明确红字、逐文件清单、二次确认、文件变化检查和处理占用保护。
- 首次关闭询问、记住偏好及设置入口；托盘后台处理、重复启动恢复原窗口，任务栏与托盘提示处理进度。
- 缺失图片从可用结果移除并提示，删除不会连带清空整个文件夹；保存、剪切及下载过程保持可取消。

## 后续优先建议

| 建议 | 理由 | 状态 |
| --- | --- | --- |
| 预览缓存管理页，显示占用和单独清理 | 长视频兼容预览会占空间，退出中断可能留下未完成缓存；目前可明确删除已登记缓存 | 尚未实现 |
| 更快的长视频预览准备 | 当前需整段下载／转码完成后播放，增加分段准备或经过验证的硬件路径可减少等待 | 尚未实现，需验证稳定性 |
| 干净 Windows 安装与第二台电脑验证 | 本机实际运行不能替代独立环境兼容性及安装验收 | 尚未验证 |
| 真实抖音样本与网络波动测试 | 平台访问、CDN 和权限会改变，Bilibili 单一样本不能代表全部来源 | 尚未完整验证 |
| HDR 长度剪切、多音轨／字幕选择 | 当前 H.264/AAC 剪切适用于已验证的普通视频，复杂音视频元数据需专门方案与样本 | 尚未实现完整保留 |
| 查看图片跨页连续浏览 | 当前查看器受结果页范围限制，长任务翻页后查看仍有重复操作 | 尚未实现 |

暂不增加更多常驻按钮。后续入口优先放在视频操作或设置页，通过默认关闭的可选项控制复杂功能。
