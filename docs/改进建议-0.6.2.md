# 拾帧 0.6.2 改进与后续建议

本轮已完成图片查看与视频裁剪的快捷键、滚轮和平移修复，弹窗按实际层级处理画面快捷键；去除拼接编辑额外焦点边框；添加可拖动画面序号、拼图宫格列数设置、多键录制、在线自动选中封面和完整链接提示；Alt 菜单改为 F2。

## 在线解析调研

Bilibili 的匿名可用格式与账号状态区分可见 [yt-dlp 的 Bilibili 解析器](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/bilibili.py)。公开视频存在可匿名获取的清晰度，平台拒绝请求或更高画质权限不能简单归结为必须登录。

抖音“Fresh cookies”问题见 [yt-dlp 官方讨论](https://github.com/yt-dlp/yt-dlp/issues/12669)，其中访客 Cookie 与登录账号是不同概念。[video-downloader 的公开分享页实现](https://github.com/zyipeng/video-downloader/blob/main/scripts/download-douyin.sh) 提供了读取移动分享页数据的思路，本项目为 Python 工作进程重新实现公开页面数据读取，并在下载前刷新页面地址。

本次加入匿名优先、独立访客会话、公开分享页回退和清晰度回退。Bilibili 实测成功；抖音目前只有结构及回退检查，真实成功率待样本验证。

## 建议优先级

| 优先级 | 建议 | 验收方式 |
| --- | --- | --- |
| P1 | 更多真实抖音公开样本 | 分别测试详情页、短链接、删除、需验证以及不同清晰度；记录匿名成功与失败类别 |
| P1 | 第二台电脑与干净 Windows 安装 | 无开发环境安装、启动、导入、导出、升级保留项目、卸载后文件保留 |
| P2 | 在线解析阶段与取消 | 显示“读取信息 / 访客重试 / 分享页回退”，允许取消长时间等待；权限错误不反复重试 |
| P2 | 裁剪时间轴可视化 | 拖动时段边界、复制区域、标出默认空档，维持目前的目标时间与边界规则 |
| P2 | 原图查看跨页 | 支持当前页、全部与仅已选，继续按需加载，避免大量原图同时占内存 |
| P3 | 序号模板扩展 | 自定义编号起点、更多符号或文字，预览与导出使用相同位置及字体尺寸 |

以上为后续建议；本轮完成范围和未验证项以 [测试报告](测试报告-0.6.2.md) 为准。
