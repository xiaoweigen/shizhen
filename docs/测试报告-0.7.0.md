## 重点验收

1. 起止时间显示分:秒.毫秒，支持小时；无效输入不写入参数。输入 `00:02.500`、`00:05.250` 得到正确范围；抽帧间隔继续按秒／张表示。
2. 截取与裁剪时间轴默认展开，可点击标题收起。拖动播放线改变实际视频时间和解码画面；起止柄和整段色块调整范围，当前播放点可设为边界。
3. 裁剪窗口可以播放、暂停、定位，不再只显示封面；分段范围和宽度保存后，实际抽帧得到对应像素。已有缩放、滚轮、空格／中键／长按平移仍可用。
4. 操作集中在“视频操作 ▾”，剪切默认未启用；勾选后才显示入口，后台也校验开关。剪切编辑可撤销时间更改和模式更改。
5. 删除中间时段后先询问是否拼接，确认后选择保存目录。拼接得到一个副本，选择否得到两个独立副本，均加入列表；声音与时长核验通过，原视频不改动。同名文件保留，新文件另存。
6. 文件位置使用系统文件管理器定位接口。自动验收拦截并核对接口与目标文件，避免反复打开桌面窗口；未以工具内的媒体查看替代该接口。
7. 真实删除弹窗包含红字、逐文件清单与额外勾选确认；未确认时按钮禁用。实际删除测试剪切副本、单张截图和在线视频缓存，原始素材及同目录无关文件保留，列表／任务记录保留，可用结果数量更新。
8. 用户提供的 Bilibili 视频在未选择登录 Cookie 的条件下解析、下载预览副本并真实播放。AV1 软件解码生成 H.264/AAC 兼容缓存，拖动及播放时间变化通过；独立下载仍是单独的菜单入口。
9. 独立下载首次遇到“网络”分类错误；同一任务重试成功，视频元信息核验完成，复用保存的视频按 2 秒间隔抽出 3 张图片。未验证所有平台或所有清晰度。
10. 首次关闭选择托盘后窗口隐藏，后台抽帧任务完成；取消关闭保持窗口可见。记住选择、重启恢复、设置入口和直接退出通过。重复启动退出新实例并恢复旧窗口，工作区不被覆盖。

关闭询问的自动测试使用原生对话框返回值替身，验证实际关闭处理与窗口状态；未手工逐一点击系统托盘图标或原生对话框。托盘事件与菜单连接另经代码检查。

## 边界与交付

安装包与最终免安装目录已生成，免安装目录实际运行；安装包压缩结构检查通过，解包后的 711 个程序文件与通过测试的目录逐一 SHA-256 相同。未在全新 Windows 或第二台电脑安装此安装包，也没有真实抖音样本。网络、权限和平台规则可能导致在线解析／下载失败，测试不代表全部链接可用。

长度剪切重新编码，时间精度受视频帧率影响，画质／大小可能变化；本轮验证普通 SDR 视频和音轨，未验证 HDR 长度剪切、字幕、多音轨或多声道保留。HDR 抽帧属于原有处理层测试范围，不能推断为 HDR 剪切验证。

兼容预览需要下载／转码时间及额外磁盘空间；当前是整段准备后播放。图片查看器仍以当前结果页为范围。删除只移动明确选中的文件至系统回收站；网络盘／特殊介质未测试，不自动改为永久删除。

源码包、最终程序及内嵌 Python 代码检查未发现被核对的私人路径、素材名、观看链接引用；截图人工核对且没有 EXIF／文本元数据。检查范围见 [隐私核对](隐私核对-0.7.0.json)，这不构成对未知秘密的绝对保证。

根目录启动入口指向 0.7.0。新版本仅在本地，公开仓库现有发行版仍为 0.6.1。测试媒体副本、原始工作区和构建临时记录在交付整理后移入回收站，保留上述脱敏报告和使用截图。
