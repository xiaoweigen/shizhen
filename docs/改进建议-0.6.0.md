## 下一轮建议

下面是后续建议，未实现/未验证项没有计入本版通过结果。

| 优先级 | 建议 | 依据与验收 |
| --- | --- | --- |
| P1 | 视频列表虚拟显示、封面复用 | 500条引用可用，但工作集约622MiB。结果列表已有虚拟行，视频列表仍创建全部条目；用500/2000条比较内存、搜索和分类拖动。 |
| P1 | 干净Windows安装/升级/卸载 | 本机免安装已测，安装程序未运行。需独立环境核对无开发依赖、0.5→0.6数据保留、安装位置、卸载后用户文件保留。 |
| P1 | 有效抖音访问状态与更多平台样本 | 用用户授权的有效Cookie验证抖音成功解析/下载、失效状态和清晰度；不读取浏览器凭据。 |
| P2 | 裁剪时间轴块、边界吸附 | 多时段数字输入较多。可拖动起止、吸附切镜、复制时段、标出默认空档；保持目标时间与相接边界规则。 |
| P2 | 场景检测预览、阈值试算 | 当前明显切镜有效，渐变可能漏检。先显示切点/张数，允许排除切点，减少反复完整导出。 |
| P2 | 备份同名冲突与批量定位 | 合并导入可能产生同名模板。增加合并/保留两份，用大小/时长/摘要辅助找回移动素材。 |
| P2 | 实拍HDR和动态4K长素材 | 目前HDR为生成样本，4K压力是短静态画面。补手机/相机、不同色彩标记、长动态素材，不从短样本推断性能。 |
| P2 | 在线脱敏诊断与有限网络重试 | 本轮一次超时、重测成功。提供可复制详情和仅针对网络错误的退避重试，不反复提交权限或链接错误。 |
| P3 | 原图跨页/只看已选 | 当前原图浏览限截图当前页；跨页和已选过滤可减少返回列表。 |
| P3 | 更多故事板文字模板 | 可补编号样式、每图独立样式、字体导入/预览，并核对中文换行。 |

优先优化视频列表内存并完成独立安装验证，其余按使用反馈安排。细节见 [测试报告-0.6.0.md](测试报告-0.6.0.md)。
